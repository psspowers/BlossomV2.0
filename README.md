# Blossom

**A privacy-first PCOS companion app**

Blossom helps you track symptoms, understand patterns, and navigate PCOS with compassion. Your data never leaves your device.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Tech Stack

- React 18 + TypeScript
- Vite build tool
- IndexedDB (via Dexie) for local storage
- Tailwind CSS + Radix UI
- Framer Motion for animations
- Progressive Web App (PWA)

## Privacy First

- No data transmission
- No analytics or tracking
- 100% local storage
- No accounts required

See [docs/PRIVACY.md](docs/PRIVACY.md) for details.
